# 随机执勤与站点经营模块

`career.js`为无依赖UMD模块，使用既有MembraneCore案例模板与状态结构。浏览器全局`MembraneCareer`；Node可require。

## 随机班次

- 确定性种子PRNG，不使用Math.random；相同profile升级、种子、任务号生成完全相同内容，不改变profile。
- 随机任务1起8件，每3次任务增加1件，最多12件。基础时间`max(170,230-任务号*4)`秒，排班升级每级增加20秒。完成全部申请且正确率至少75%、稳态高于0才算结班；该门槛由Core.next执行，防止高防护装备下全部拒绝也能获胜。
- 事件：常规执勤、渗透警报、GLUT检修、能量限供、证件专项稽查。渗透警报即使在8件首班也保证至少2份水申请。检修移除carrier许可证并明确葡萄糖拒绝原因；能量限供仅安排一份泵任务，仍保证基础ATP足额。
- 首两份为合法的中性小分子与Na⁺运输；其余按种子洗牌，至少4类货物、2份拒绝和一份合法完整泵任务。
- O₂、CO₂、乙醇、葡萄糖随机改变浓度与方向，拒绝逆净驱动力申请。水假定同压、不可透溶质，水净移动朝溶质较高侧。Na⁺或采用145外/12内、膜内−70mV向内，或显式标注电压钳实验12外/145内、膜内+40mV向外，两种场景浓度与电势驱动一致。
- 泵保持3Na⁺出/2K⁺入每循环1ATP。总ATP=全部合法泵任务需求＋电池升级备用，不制造靠购买才能过关的任务。囊泡路线未开放，胰岛素申请明确拒绝本站小溶质路线。
- 伪装申请用真实name/formula与性质，declared为另一种物质；始终拒绝，scan给出证据，演出沿用真实物质。

## 经费、经验与升级

- 新档案160游戏币。每件正确获得8＋连对加成（最多额外8）；错误罚12，余额不低于0。正确20XP，错误5XP。
- 完整完成一班薪资40；零差错再加30；每剩30秒加3。失败无结班薪资，逐件收入保留。
- 排班延时与稳态防护各3级，价格120/240/420；ATP储备2级，价格160/300，用作错误拨付后的额度保障。随机班中错误放行且已拨付1 ATP时，会冻结至多1个可用ATP额度（游戏调度规则，非错误生化过程实际水解ATP）；正确泵仍每循环水解1 ATP，拒绝不冻结额度。升级仅下一班随机任务生效，教学科学规则保持原样。
- 随机班次一次性应急修复60，恢复25稳态；只有仍存活、未修复的进行中随机班次可用。不复活、无强制消费、无负债。
- 200XP一等级；见习／正式／资深／首席检查员。`rank.nextXp`为下一等级的累计XP门槛，`rank.progress`为本级0..1比例。

## 成就与公平性

12项成就均按可观察的实际统计解锁，各奖励一次：首枚印章、5连对、零差错班、教学完成、首次随机执勤、3班随机、8类分子正确处理、3次识破伪装、5次泵循环、10次被动通行、3次升级、使用应急修复后通过随机班次审计。

`record`按`runId/caseId`防重复入账；`settle`按`runId/day`防重复结薪。重新加载反馈不会再次给钱；成就奖励另列账本，不计入`record.cashDelta`或`settle.total`，避免把薪资与成就混成一个不透明数值。账本保留最近40项；裁决收据500项、结班收据300项。UI必须为新尝试生成新的runId/seed，父代理已负责。

财务审查：无充值或真实货币；错判扣款封底0，升级不增加物理通透性，能源基准足以完成全班。失败后重新做题赚逐件收入是练习回报，不是必须刷钱的软锁。应急修复每班一次且不复活，不能无限用经费抵销判断。每次购置原子扣款，余额不足、未知设施、已满级均不扣钱。

## 持久化与接口

存储键`membrane-career-v2`。`load(storage,legacyBest)`从已通过旧版三班的最高分迁移教学解锁；不凭分数补造过去统计。损坏JSON、安全存储拒绝不抛错。`save`返回布尔值。

`sanitizeRun`与`sanitizeProfile`导出。恢复校验assignment标题、事件、rules、case schema、route/port、合法色值、队列数量等；异常run丢弃，保留可用个人档案。UI查验状态、feedback.result.finances与教学班间state.bill已结算缓存保留；稳态0的反馈允许恢复并由next进入失败。

接口：newProfile/load/save/makeAssignment/newRun/record/settle/buy/repair/rank/progress/checkAchievements，常量UPGRADES、ACHIEVEMENTS、STORAGE_KEY。`progress(profile,id)`给出`{value,goal}`，解锁数组为完整静态成就对象；profile.achievements仅保存id字符串。

统计字段：total/correct/mistakes/bestCombo/types/pumps/fakes/passive/careerCleared/cleanShifts/totalShifts/upgradesBought/comebacks/tutorialWins/failedShifts/creditsEarned/creditsSpent。types为物质name字符串数组。

## 验证

先运行缺少career.js的失败测试，再实现。`node work/career.test.cjs`共17项通过：250个种子调度不变式、29班由真实Core完美通关、经济边界、重复入账、成就、修复、损坏存档、UI与反馈恢复、恶意颜色/缺失事件等。

成就可达性：逆风结班按“使用应急修复后成功完成随机班次”判定，不再要求低于40稳态，避免高等级永久防护与75%审计门槛叠加后使成就无法达成。
