## 演出设计

| 物质／任务 | 专属形态与演出 | 时长 |
|---|---|---|
| 氧气 | 双原子结伴转动，直接穿过脂质区域 | 3.5秒 |
| 二氧化碳 | 线形分子从胞内向外扩散 | 3.8秒 |
| 乙醇 | 两亲性小分子转动、穿过脂质双层 | 3.8秒 |
| 水 | 水通道开放，小水分子排列通过 | 4.4秒 |
| 葡萄糖 | 六元环示意，GLUT结合、闭合、构象改变、向另一侧释放 | 5秒 |
| Na⁺ | 水合层靠近孔道，选择性筛检与重新配位，释放后恢复水合 | 4.4秒 |
| 钠钾泵循环 | 3 Na⁺从胞内向外；1 ATP水解为ADP＋Pi；2 K⁺从胞外向内 | 6.2秒 |
| 胰岛素 | 分泌囊泡停靠，因本站未授权胞吐而返回原侧队列 | 3.2秒 |

扫描前统一显示封装箱，不泄露真实身份。扫描会展示分子形态；采样显示驱动力。错误放行不会被画成成功穿膜，而会出现边界拦截与审计。动画、尺度和速度均为示意，不是分子动力学模拟。

支持重播、跳过、暂停。直接处理下一位会终止上一次演出并清除发光等效果。系统设置为减少动态效果时，演出缩短为650毫秒且停止环境漂浮。

`theatre.html`为不计分演出图鉴，可直接切换全部8类。`stage.js`为动作与分子形状的可编辑源文件。
